# CUET PDF Collection & Organization Guide

## Overview

This guide walks through **Phase 1: Data Collection** to gather authentic CUET UG papers (2022-2025) from verified public sources.

## Quick Start (3 Steps)

### Step 1: Identify Available PDFs

Use the comprehensive source list in [CUET_SOURCES.md](CUET_SOURCES.md) to find papers:

**Highest Priority Sources:**
- https://www.nta.ac.in/ (Official NTA portal)
- https://cuet.nta.ac.in/ (Official CUET portal)
- https://ncert.nic.in/ (Economics + Business textbooks - free)

**Secondary Sources:**
- https://www.vedantu.com/cuet (Free mock tests)
- https://www.allen.ac.in/ (Test series)
- https://www.byju.com/ (Sample papers)

### Step 2: Download & Organize

Create folders and download PDFs using this naming convention:

```
Subject_Year_Source_##.pdf
```

Examples:
- `Business_Studies_2024_NTA_01.pdf`
- `Economics_2023_NCERT_02.pdf`
- `English_2022_Vedantu_03.pdf`
- `General_Test_2025_Allen_01.pdf`

### Step 3: Register with Collector

Use the Python script to register files:

```bash
cd scripts
python pdf_collector.py
```

Edit the script's `main()` function to register downloaded files:

```python
collector.add_manual_pdf(
    subject='Business_Studies',
    file_path='data/Business_Studies/Business_Studies_2024_NTA_01.pdf',
    year=2024,
    source='NTA Official',
    is_pyq=True,
    has_answer_key=True,
    url='https://www.nta.ac.in/'
)
```

## Automation Scripts

### Batch Registration Script

Create `scripts/register_pdfs.py`:

```python
#!/usr/bin/env python3
import os
from pathlib import Path
from pdf_collector import CUETCollector

collector = CUETCollector('.')

# Auto-scan data directory
for subject_dir in Path('data').iterdir():
    if subject_dir.is_dir():
        subject = subject_dir.name
        
        for pdf_file in subject_dir.glob('*.pdf'):
            # Parse filename: Subject_Year_Source_##.pdf
            parts = pdf_file.stem.split('_')
            
            if len(parts) >= 3:
                year = int(parts[1])
                source = '_'.join(parts[2:-1])
                is_pyq = 'NTA' in source or 'Official' in source
                
                # Register
                collector.add_manual_pdf(
                    subject=subject,
                    file_path=str(pdf_file),
                    year=year,
                    source=source,
                    is_pyq=is_pyq,
                    has_answer_key=True,  # Update manually if needed
                    url='[manual-entry]'
                )

# Generate outputs
collector.generate_index_md()
collector.generate_json_manifest()
collector.generate_report()

print("✓ All PDFs registered and indexed")
```

## Duplicate Detection

PDFs are considered duplicates if they have:

- Same subject + year + source
- Identical file content (via hash comparison)
- Same question set with minor formatting differences

**Prevention**: Check filename before downloading.
