## ⚡ Quick Commands

### Python Setup
```bash
python -m venv venv
source venv/bin/activate  # Mac/Linux
venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

### Phase 2: Process PDFs
```bash
python scripts/pdf_processor.py
# Output: ~1,300 questions in /processed/
```

### Phase 3: Next.js Setup
```bash
cd app
npm install
cp .env.example .env.local
# Edit .env.local
npx prisma db push
npm run dev
# Access http://localhost:3000
```

### Database
```bash
npx prisma studio  # View database GUI
npx prisma migrate dev --name migration_name  # Create migration
```

## 🆘 Common Questions

**Q: Do I need to download all 20 years of papers?**
A: No, papers from 2022-2025 are sufficient (4 years). Aim for 32-40 total PDFs.

**Q: What if extraction rate is low?**
A: Manual review and addition via admin panel is an option. Aim for >85% auto-extraction.

**Q: Can I start before all PDFs are collected?**
A: Yes, you can work on Phase 3 setup while collecting PDFs.

**Q: How long does PDF processing take?**
A: ~2-3 minutes for 32 PDFs on a modern computer.

**Q: Do I need to train an ML model?**
A: No, the platform uses rule-based extraction and off-the-shelf APIs.

**Q: Can I use different styling?**
A: Yes, Tailwind CSS is easily customizable. Modify tailwind.config.js.

**Q: Is database required?**
A: Yes, PostgreSQL is required for data persistence.

**Q: Can I deploy without all features?**
A: Yes, deploy MVP after Phase 4 (Exam Engine) and add features incrementally.
